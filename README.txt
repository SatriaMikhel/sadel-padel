SADEL PADEL COMPANY PROFILE — V4

This version fixes the main UI/UX issues found during review:
- Hero content is visible without JavaScript; only below-fold reveal animations depend on .js.
- Light-background accent text uses forest green for readable contrast.
- Space mosaic no longer leaves an empty desktop grid cell.
- Hero and Community use different photos.
- Rail controls/hint only appear when the rail actually overflows (mobile / narrow screens).
- Button/link targets are consistent and use internal arrows for internal anchors.
- Body/UI type is larger and the footer touch targets are padded.
- Booking time uses a 30-minute step; start + duration is validated against 23.00 closing time.
- Booking form always produces a useful WhatsApp/share flow and offers Copy details as fallback.
- Focus indicators are visible and stronger.
- Main SADEL mascot lockup appears in the hero; monogram remains secondary in the header.
- No fake business stats are shown.
- Responsive image aspect ratios are explicit on mobile.
- Reduced-motion support is preserved.
